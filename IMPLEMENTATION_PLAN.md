# Implementation plan

1. Workspace, desktop bootstrap, validated private multiplayer lobby.
2. Original card data, deterministic engine, deck validation, automated victory simulation.
3. Authoritative projections, revision checking, reconnect and snapshot recovery.
4. Interactive battlefield, legal action feedback, history and results.
5. Gallery, deck builder, persistent server accounts and account-owned saved decks. Friends connect using a configurable server address plus private room code/password; support private Tailscale access and document HTTPS hosting.
6. Four-player formats and integration tests.
7. Native release workflow, hosting and integration documentation.

Each milestone requires type checking and relevant tests before it can be marked verified. This directory began empty; Git was initialized on 2026-10-12 to preserve the current project checkpoint and future milestones. Native macOS packaging requires a macOS runner. Signing requires certificates supplied separately.
